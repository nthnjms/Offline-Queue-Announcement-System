Offline Queue Announcement System

Runs entirely offline, no server or internet connection required.

🎛️ Control Panel Open this on the operator's computer to call tickets. 📺 Public Display Open this on the TV, projector, or second monitor.

How to set up

  1. Open Control Panel on the computer the operator will use to call tickets.
  2. Open Public Display — drag that window to the TV/projector, or connect that screen via HDMI and open it there, then use the ⛶ fullscreen button in its bottom-right corner.
  3. On the Display screen, tap anywhere once when prompted — this is a one-time step browsers require before they'll allow announcement sound to play.
  4. In Control Panel, open Settings to set your office name, logo, number of counters, and theme color before you start.
  5. Call a ticket from Control Panel — the Display updates, rings, and announces it instantly.
